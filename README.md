# ই দোকানি অ্যাপের ডোমেইন

app-config.json ফাইলের website_url পরিবর্তন করে Commit changes করুন। নতুন ঠিকানা HTTPS হতে হবে। অ্যাপ আবার খুললে নতুন ঠিকানা ব্যবহার করবে। GitHub সাময়িকভাবে বন্ধ থাকলে সর্বশেষ সংরক্ষিত ঠিকানা চলবে।

ডোমেইন বদলানোর আগে নতুন হোস্টে একই অ্যাপ ও ডেটাবেস স্থানান্তর করুন। নতুন ডোমেইনে প্রথমবার আবার লগইন করতে হবে। এই repository-র নাম, account বা main branch বদলাবেন না। এখানে কোনো password/API key রাখবেন না।
